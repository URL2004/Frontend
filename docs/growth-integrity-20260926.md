# 로그인·구매·검색 개선 운영 안내

## 변경 사항

- Google/Kakao 인증 시작과 결과에 무작위 시도 ID, 제공자, 흐름, 오류 단계를 추가했다. GA 이벤트 이름은 유지하며 카카오 원시 메시지를 분석 도구로 보내지 않는다.
- 카카오 리다이렉트의 사용자 취소도 콜백으로 처리하고 인증 쿼리를 제거한다. SDK 로딩으로 클릭 권한이 끝난 경우 다음 명시적 클릭에서 팝업을 연다.
- 지원하지 않는 Google 인앱 로그인에는 외부 브라우저 안내를 제공한다. 기기 간 입력은 자동 전송되지 않으므로 사용자가 글을 복사할 수 있다. 결제·OAuth 비밀 쿼리는 외부 브라우저 링크에서 제거한다.
- 결제 시작·오류·취소를 기존 주문 ID로 연결하고, 결제창 실패를 두 번 기록하던 경로를 통합했다. 주문 생성 전 취소는 별도 분류다.
- `/detect-report`의 사용 순서·점수 해석·표절 검사 구분을 보강하고 연구노트 본문 연결을 추가했다.

## GA4 설정

속성 `532742030`에서 이벤트 범위 맞춤 측정기준 `method`(Login Provider), `auth_stage`(Authentication Stage), `error_code`(Authentication Error Code)를 추가한다. 기존 매개변수가 등록돼 있으면 재사용한다. `attempt_id`나 `transaction_id`를 고유값이 많은 맞춤 차원으로 등록하지 않는다. `attempt_id` 연결 분석의 정본은 백엔드 진단 로그다. 신규 주요 이벤트를 추가하지 않는다.

자체 `traffic_*`는 GA4 세션 획득 차원과 별도다. 기존 source 보호·수동 SPA 조회·관리자 제외·추천 제외 설정은 새 브라우저와 기존 방문 브라우저에서 각각 확인한다. 과거 귀속 잔존을 신규 회귀로 단정하지 않는다.

## 검색 역할과 확인 도구

| 대상 | 역할 |
| --- | --- |
| `/` | 브랜드 검색과 즉시 도구 사용 |
| `/detect-report` | 한국어 AI 검사 방법·결과 해석·비용·한계 |
| `/blog/ai-detection-evaluation-notes` | 특정 개발 표본의 검증 기록, 전체 정확도 보장과 구분 |
| `/blog/ai-detector-vs-plagiarism-checker` | AI 감지와 표절 검사의 검색 의도 구분 |

고정 검색어는 `ai 검사기`, `ai검사기`, `ai 판독기`, `ai판독기`, `ai 탐지기`, `ai탐지기`다. 페이지·기기별 7일 클릭/노출/CTR/순위를 보며 브랜드 상승에 섞지 않는다. 개별 검색어와 구매자를 직접 연결했다고 표현하지 않는다.

`node scripts/growth-seo-audit.mjs --out=../../reports/growth-seo.local.json`은 공개 사이트맵과 보고서의 미색인 10개 URL을 검사한다. HTTP, 대표 URL, noindex, H1, 본문 존재, 내부 링크를 기록한다. HTTP 성공이나 본문 길이가 색인/품질 보장은 아니며 Search Console 상태는 별도로 확인한다. 페이지가 이미 정상이라면 새 페이지 생성이나 불필요한 canonical 변경을 하지 않는다.

## 실기기 검증표

대상: 데스크톱 Chrome, iPhone Safari, Android Chrome, iPad Safari, Instagram 인앱, Kakao 인앱. 데스크톱의 화면 크기 변경은 실제 Safari/앱 검증을 대체하지 않는다.

각 환경에서 Google/Kakao 정상 로그인, 취소, 팝업 차단, 네트워크 단절, 재시도, 입력 복원, 가격/크레딧 안내, 결제 복귀, 원래 작업 복귀를 확인한다. 성공 콜백 재방문·새로고침 시 이중 승인/차감/크레딧 지급이 없어야 한다. 실결제는 운영자가 검증하며 합성 자동 테스트를 실제 결제 완료로 기록하지 않는다.

현재 시점의 코드·테스트·배포 완료와 7일/4주 성과 관측은 별도로 기록한다. 광고 예산과 가격은 이번 변경 대상이 아니다.
