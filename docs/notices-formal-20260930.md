# 공지사항 격식체 정비

- 기본 공지 26건과 로그인 후 표시되는 기존 원격 공지 4건의 제목·본문을 정비했습니다.
- 운영 휴머나이징 엔진 `gpt-prod-v2.5.95`에 공지 장르와 격식체 요청을 적용해 30건을 처리하고, 남아 있는 해요체·소제목·목록 간격을 별도 검수했습니다.
- 공지별 날짜·시간·가격·크레딧·수치와 적용 시점, 소급 여부, 환불·무차감 조건, 결과의 한계를 보존했습니다. 분류·게시일·조회수·중요 표시와 기존 공개 범위도 유지합니다.
- 로컬 공지의 옛 제목은 원격 중복 제외 목록에 추가했습니다.
- 원격 4건은 기존 문서 ID와 원본 제목·본문이 일치할 때만 검수 문구를 표시합니다. 목록과 직접 상세 조회에 같은 처리를 적용하며, 관리자가 이후 원격 문서를 수정하면 수정한 문구가 우선합니다. Firestore 문서는 변경하지 않았습니다.
- 공지 회귀 검사는 공지별 수치 보존, 정책 조건, 30건의 격식체, 이전 제목 중복 제외, 원격 문구 적용과 이후 관리자 수정 보존을 검증합니다.
