# 관리자 유입·UTM

관리자 → **유입·UTM**에서 링크 생성과 신규 가입 집계를 사용한다. 사용자 관리와 별도 탭이며, 선택할 때만 가입 집계 API를 조회한다.

## 링크 규칙

| 화면 입력 | 저장 값 | 예시 |
| --- | --- | --- |
| 플랫폼 | `utm_source` | `instagram` |
| 채널 · 계정명 | `utm_campaign` | `gyopi_official` |
| 영상 이름 | `utm_content` | `video_01` |
| 홍보 방식 | `utm_medium` | `social` |

같은 플랫폼·계정에는 같은 채널 이름을 쓰고 영상마다 다른 영상 이름을 쓴다. 영문은 소문자로, 공백은 밑줄로 정리한다. 한글 이름도 지원한다. 이름은 100자 이내의 글자·숫자·밑줄·하이픈만 허용하며 계정명의 앞 `@`는 제거한다.

도착 주소는 HTTPS 교피 도메인(`gpkorea.ai.kr`, `www.gpkorea.ai.kr`)만 허용한다. 다른 쿼리와 해시는 유지하고 기존 UTM 파라미터는 새 입력으로 교체한다. 생성은 URL 구성만 수행하며 서버에 링크 목록을 등록하지 않는다. 입력을 수정하면 기존 결과를 숨겨 예전 링크를 잘못 복사하지 않도록 한다.

예: `https://gpkorea.ai.kr/?utm_source=instagram&utm_medium=social&utm_campaign=gyopi_official&utm_content=video_01`

## 집계

기존 가입 attribution API와 저장 구조를 사용한다. 과거 링크의 캠페인 값은 채널 칸에 표시한다. 플랫폼·채널 필터와 영상 검색을 제공하며 집계 단위를 플랫폼/채널/영상으로 바꿀 수 있다. 각 단위에서 홍보 방식이 다른 동일 그룹의 가입 수를 합산한다. 최초 유입과 가입 직전 유입은 별개 기준이며 합산하지 않는다.

**이 영상 가입 실적 보기**는 생성한 플랫폼·채널·영상을 정확히 선택한다. 아직 가입이 없어도 필터를 유지하고 0명과 빈 상태를 보여준다. 검색창을 직접 편집하면 부분 검색으로 바뀐다. 생성만 한 링크는 가입 기록이 생기기 전 전체 목록에 표시되지 않는다.

기간, 관리자 제외, 삭제된 계정 제외, 미기록 구분, 조회 한도와 오류 처리는 기존 정책을 유지한다.

## 인앱 로그인과 브라우저 이동

인스타그램·Facebook 인앱에서는 카카오 로그인을 먼저 안내한다. Google 버튼은 외부 브라우저 안내로 연결하며 Google 인증을 인앱에서 강제로 실행하지 않는다. iOS에서는 앱 메뉴 안내와 로그인 주소 복사를 제공하고, Android에서는 Chrome intent와 같은 주소의 fallback을 사용한다. 카카오톡은 두 로그인 모두 외부 브라우저로 안내한다.

외부 브라우저로 전달하는 주소는 탐색 파라미터와 유입 정보만 포함한다. OAuth 코드·state·토큰·결제 정보·입력 글은 포함하지 않는다. 최초/마지막 유입과 원래 포착 시각을 10분 동안 유효한 `gp_attribution` 메타데이터로 이어 주며, 수신 후 URL에서 제거한다. 일반 UTM도 함께 전달하므로 10분 이후에는 일반 캠페인 링크로 동작한다. 이는 인증 수단이 아니며, 서버가 기존과 같이 가입 유입 필드를 검증한다.

저장소 접근 실패 시 sessionStorage와 같은 페이지의 메모리를 사용한다. 모든 브라우저 저장소가 차단된 상태에서 페이지를 완전히 종료하면 복원할 수 없다. `www.gpkorea.ai.kr`는 경로·쿼리를 유지한 채 기본 도메인으로 이동해 인증과 저장소의 origin을 통일한다.

최초 90일·마지막 30일 기준과 새로운 외부 유입의 last-touch 갱신 정책은 유지한다. 과거 영상 미기록 가입자를 추정하여 캠페인에 추가하지 않는다. 이번 수정은 과거 수치를 보정하지 않는다.
