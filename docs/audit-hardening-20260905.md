# 홈페이지 감사 수정 기록 — 2026-09-05

- 360px에서 AI 감지 버튼의 문구가 줄어 사라지지 않도록 최소 너비와 축소 규칙을 수정했다. 예상 비용 안내는 유지한다.
- 한국어 원문 입력란에 접근성 이름을 추가했다.
- 휴머나이징 공지의 일본어·중국어 지원 설명을 한국어 전용 엔진의 실제 계약에 맞췄다.
- 문단 보강 폴링의 HTTP 요청과 JSON 읽기에 15초 timeout을 적용했다. 사용자용 실행 중 취소·중단 기능은 추가하지 않았다.
- 보강 결과를 받으면 이전 검증 배지를 지우고 새 결과의 안내·보존 계측을 다시 그린다.
- 감지의 구조화 근거에 위치가 있으면 참고 문장 번호를 표시한다.
- 앱 스크립트를 미리 병렬로 가져오되 실행 순서는 기존 의존성을 유지한다. 외부 폰트 다운로드는 앱 시작을 막지 않는다.
- 배포 자산은 CSS/JS를 압축한 뒤 내용 hash를 계산한다. HTML 및 다른 classic script가 사용하는 전역 이름을 바꾸지 않도록 identifier 축약은 끈다.
- 외부 script 출처 제한을 enforcing CSP에 적용하고 report-only 정책에도 수신 경로를 추가했다. 기존 inline handler 때문에 `unsafe-inline`은 유지하며, 이 변경이 모든 XSS를 제거한다는 뜻은 아니다.

## 검증

프런트엔드 테스트 250개 중 249개 통과, 기존 1개 skip. 저장소 밖 복사본에서 `npm run build` 성공. 빌드된 페이지를 360px 브라우저에서 열어 버튼 문구, 접근성 이름, 모드 전환을 확인했다. 운영 CSP를 로컬에 적용한 페이지의 초기 실행에서도 console error가 없었다. 로그인·결제·유료 변환은 실행하지 않았다.

| 자산 | 원본 gzip | 빌드 gzip |
| --- | ---: | ---: |

| redesign.css | 108,580 B | 72,234 B |

합계 303,913 B → 230,923 B, 약 24% 감소. 로컬 gzip 비교이며 CDN의 실제 전송량이나 모바일 실측 LCP 개선률을 의미하지 않는다. 관리자 코드와 CSS의 구조적 분리는 후속 최적화 여지가 있다.

백엔드의 `/csp-report`를 먼저 배포한 뒤 이 프런트엔드를 배포한다. 로컬 검증용 빌드에는 운영 환경 변수를 복사하지 않았다. 운영 배포 및 실제 로그인·결제 제공자 연동 검증은 별도로 남아 있다.
