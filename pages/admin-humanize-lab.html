Writing Lab 실험

자소서 생성 랩 — 생성 → 휴머나이징 결합

사실 카드에 적힌 경험·수치만으로 문항 답변을 생성하고, 곧바로 휴머나이징과 무날조 검수를 통과시킵니다. 사실 카드에 없는 경험·수치는 날조 후보로 표시됩니다.

사실 카드 — 본문에 들어갈 수 있는 유일한 근거입니다. 최소 한 칸은 채워야 생성이 시작됩니다.

생성 랩 결과

① 생성 초안 → ② 휴머나이징 결과 → ③ 사실 카드 기준 검수 리포트(결정론·무LLM) 순서로 채워집니다.
